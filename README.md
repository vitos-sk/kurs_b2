# Немецкий B2 — только главное

Интерактивный курс для подготовки к экзамену B2: грамматика простыми словами, слова-карточки, готовые фразы, тест и раздел «Ошибки». Работает на телефоне как приложение и без интернета.

## Как выложить на GitHub Pages (можно прямо с телефона)

1. Зайди на github.com → «+» → **New repository**. Назови, например, `deutsch-b2`, поставь **Public** → Create.
2. В репозитории: **Add file → Upload files** → загрузи все файлы из архива (index.html, sw.js, manifest.webmanifest, icon-*.png) → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты курс будет по адресу `https://ТВОЙ_НИК.github.io/deutsch-b2/`.
5. Открой адрес на телефоне → меню браузера → «Добавить на главный экран».

## Обновление курса

Заменил `index.html` — открой `sw.js` и поменяй `VERSION` (например, `b2-v2` → `b2-v3`), чтобы телефон подтянул новую версию.

## Прогресс

Сохраняется автоматически в браузере телефона. В разделе «Мой прогресс» можно скачать файл или скопировать код, чтобы перенести его на другое устройство.
